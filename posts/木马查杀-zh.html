木马查杀？快速就能上手的6种方法

木马查杀的最短路径是：Windows 用户直接跑一次 Windows Defender 全盘扫描（约 45–90 分钟），Linux 用户跑一次 clamscan 全盘扫描，两者都能覆盖 90% 以上的常见木马。如果不想装任何软件，也可以用在线木马查杀工具，把可疑文件直接上传分析，5 分钟内出结果。下面这 6 种方法可以独立使用，也可以组合使用。

6 种方法

方法 1：Windows Defender 全盘扫描（系统自带）

Windows 10 与 Windows 11 都内置了 Windows Defender，不需要额外安装。

  1. 按 Win + I 打开「设置」，进入「隐私和安全性」→「Windows 安全中心」。
  2. 点击「病毒和威胁防护」→「扫描选项」。
  3. 选择「完全扫描」（不是「快速扫描」），点击「立即扫描」。
  4. 等待扫描结束。以一台 500 GB 硬盘、约 15 万个文件的笔记本为例，完全扫描耗时通常在 45–90 分钟之间。
  5. 扫描结束后，在「保护历史记录」中查看被隔离的文件。隔离区默认路径是 C:\ProgramData\Microsoft\Windows Defender\Scans\Quarantine，可以右键恢复误杀的文件。

如果只想查特定目录，例如 D:\Downloads，可以在「扫描选项」里选「自定义扫描」，把路径填进去。

方法 2：PowerShell 命令行调用 Defender

适合想写脚本、做定时任务、或者批量处理多台机器的场景。

打开 PowerShell（右键开始菜单 →「终端」或「Windows PowerShell」），执行：

Start-MpScan -ScanType FullScan

查看扫描状态：

Get-MpComputerStatus | Select ScanType, QuickScanEndTime, FullScanEndTime, LastQuickScanEndTime, LastFullScanEndTime

只扫描指定目录：

Start-MpScan -ScanType CustomScan -CustomScanPath "D:\Downloads","E:\Temp"

查看当前威胁数：

Get-MpThreatDetection | Select ThreatID, ThreatName, InitialDetectionTime

如果想每 7 天自动跑一次，可以用 Register-ScheduledTask 注册一个计划任务，触发器设置为 Weekly，重复间隔 7 天。

方法 3：Linux 下用 ClamAV

ClamAV 是开源的免费杀毒引擎，Ubuntu、Debian、CentOS 都支持。

# Ubuntu / Debian
sudo apt update && sudo apt install clamav clamav-daemon

# CentOS / RHEL
sudo yum install clamav clamav-update

# 更新病毒库
sudo freshclam

# 扫描整个根目录（约 500 GB 硬盘，耗时 3–6 小时）
sudo clamscan -r / --infected --log=/var/log/clamscan.log

# 只扫描 /home 与 /tmp
sudo clamscan -r /home /tmp --infected --log=/var/log/clamscan.log

常用参数：-r 递归，--infected 只输出感染文件，--remove 直接删除，-i 显示感染文件，--max-filesize=250M 限制单文件大小。

扫描完成后查看日志：

grep -i "INFECTED" /var/log/clamscan.log

如果要把扫描做成每天凌晨 3 点自动执行，编辑 root 的 crontab：

sudo crontab -e
# 加入
0 3 * * * /usr/bin/clamscan -r /home --log=/var/log/clamscan.log >> /var/log/clamscan-cron.log 2>&1

方法 4：离线启动盘扫描（应对顽固木马）

有些木马会注入到系统启动项，导致杀毒软件根本跑不起来。这时需要用一个从外部启动的镜像来扫描。

  1. 准备一个至少 16 GB 的 U 盘。
  2. 在另一台干净电脑上，用「媒体创建工具」制作 Windows 安装 U 盘（下载约 5 GB，写入耗时 10–15 分钟）。
  3. 把 U 盘插到待扫描的电脑上，开机按 F12、F2 或 Del 进入启动菜单，选择从 U 盘启动。
  4. 进入安装界面后按 Shift + F10 调出命令提示符。
  5. 执行：
C:\Windows\System32\MpCmdRun.exe -Scan -ScanType 2 -Filepath E:\

其中 -ScanType 2 表示全盘扫描，E:\ 是 Windows 安装盘在 WinPE 环境下的盘符（不一定是 E，先用 dir 确认）。扫描 500 GB 硬盘通常需要 2–3 小时。

扫描完成后，感染文件的路径会打印在终端里，可以直接 del 删除。

方法 5：用 tcpdump 抓包看可疑外连

有些木马不修改文件，而是常驻内存定期回连 C2 服务器。这时用网络层排查更直接。

Linux 下：

sudo apt install tcpdump
sudo tcpdump -i eth0 -n port 80 or port 443 or port 8080 -w /tmp/scan.pcap

参数含义：-i eth0 指定网卡，-n 不解析域名，-w 把结果写成 pcap 文件。抓包 5–10 分钟后 Ctrl + C 停止，用 Wireshark 打开分析。

重点看：连接数异常多的目标 IP、非常规端口（例如 4444、8080、6667）、以及反复握手但无数据传输的会话。

Windows 下可以用 PowerShell 的 Get-NetTCPConnection：

Get-NetTCPConnection -State Established | Sort-Object RemotePort -Descending | Select -First 20

看到某个本地进程连向陌生的境外 IP，基本就是可疑外连。

方法 6：在线木马查杀（最省事的一种）

如果不想装任何软件、也不想跑几十分钟的扫描，可以把可疑文件直接上传到 opentrojan.com 在线分析。

  1. 打开浏览器，进入网站，把文件拖到上传区（单文件上限 100 MB，超过的要分卷或本地先扫描）。
  2. 点击「开始分析」，等待 30 秒到 2 分钟（取决于文件数量和服务器负载）。
  3. 结果页会显示：文件哈希（MD5 / SHA1 / SHA256）、检测引擎命中数（例如 24/71 命中）、威胁类型（Trojan.Generic、Backdoor.Agent 等）、行为分析（是否写注册表、是否创建计划任务、是否连接外部 IP）。
  4. 如果命中数超过 5/71，基本可以判定为木马，直接删除原文件；如果命中数为 0，也不代表 100% 安全，建议再用方法 1 或方法 3 交叉验证一次。

在线方式适合：怀疑某个下载包、某个 exe、某个 apk 是不是木马，或者只是想快速比对文件哈希。它不能替代全盘扫描，但作为第一步排查非常省事。

常见问题

Q1：这些方法能查出隐藏的 rootkit 吗？

普通全盘扫描对文件型木马有效，但对驱动级 rootkit 覆盖有限。rootkit 通常要配合方法 4（离线启动盘扫描）或者用专门的 rootkit 检测工具（例如 rkhunter、chkrootkit）才能定位。判断依据是：如果全盘扫描报 0 感染但系统行为异常（例如 CPU 常驻 30% 以上、网络流量异常、任务管理器看不到可疑进程），大概率是 rootkit。

Q2：扫描完是不是就万事大吉了？

不是。木马查杀至少要覆盖三个层面：文件层（全盘扫描）、内存层（进程与驱动）、网络层（外连 IP）。建议至少跑一次全盘扫描 + 一次 tcpdump 抓包，再手动检查 C:\Windows\System32\drivers 与 C:\Windows\Tasks 目录里有没有陌生文件。

Q3：在线木马查杀够不够用？

只够用来判定单个文件。它不能扫描整个磁盘，也不能发现内存马和 rootkit。适合的场景是：从网上下载了一个 exe，不确定能不能打开，先传上去看看哈希和检测命中数。

Q4：木马查杀需要多久做一次？

日常建议每 2–4 周跑一次全盘扫描。Windows Defender 默认每 7 天做一次快速扫描，可以手动改成全盘。Linux 服务器可以用 cron 每天凌晨 3 点跑一次 ClamAV。

Q5：杀毒软件本身被木马禁用了怎么办？

三种办法：一是进安全模式（开机按 F8 或在设置里选「高级启动」→「疑难解答」→「高级选项」→「启动设置」→ 选 4 或 5），安全模式下大部分木马不会加载；二是用方法 4 的离线启动盘，从外部系统扫描；三是用另一台干净电脑制作一个 Linux Live USB，挂载原硬盘扫描。

木马查杀这件事，工具只是入口，思路才是关键。日常场景下 Windows Defender 或 ClamAV 一次全盘扫描就能解决大部分问题；遇到顽固木马就切换到离线启动盘；怀疑有 C2 回连就抓包看网络；只想知道某个文件是不是木马就用在线方式快速判定。把这 6 种方法按场景挑一两个组合起来用，基本能覆盖 95% 以上的木马查杀需求。
